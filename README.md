# stock-kb — 个股与赛道研究知识库

个人维护的股票研究笔记库。每只标的一组结构化文档（论点 / 财务 / 概览 / 变更日志），
外加 ETF、赛道分析与市场日报周报月报。中英双语（`*.md` 英文，`*.zh.md` 中文）。

## 文档约定

**论点文件（thesis）** 按固定结构展开：商业模式 → 财务 → 护城河 → 管理层 →
风险 → 情景与概率加权预期（PW EV）→ 结论 → 监控清单 → **论点破裂触发器**。

最后一项是核心：每份论点都列出「什么情况出现就必须重新评估」的具体条件。
判断可以错，但错了要能被机制发现，而不是靠事后回想。

**技术分析**采用 SEPA（Minervini）框架：Stage 1–4 阶段判定、8 条趋势模板、
VCP / 平台整理 / 杯柄等形态识别。
