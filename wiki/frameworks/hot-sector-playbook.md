# 热赛道个股进出场 Playbook

> 适用：赛道论文（`wiki/sectors/<slug>.md`）§4 生命周期 = **萌芽 / 成长** 的赛道内个股卫星仓。
> 成熟赛道个股走蓝筹规则（不适用本文）。
> 与 `synthesis.md` Roth 五桶框架配合；进出场执行配合 `/stock-entry`、`/stock-exit --profile hot-sector`。

---

## 一、适用判定

| 赛道论文 §4 生命周期 | 个股规则 |
|---------------------|---------|
| 萌芽 / 成长 | **本 playbook**（投机型：免费股 + 抛物线 + 无 LTCG） |
| 成熟 | 蓝筹规则（论文止损 / LTCG 长持） |

## 二、入场（个股卫星）

| 条件 | 规则 |
|------|------|
| 前置闸门 | 赛道论文 §9 可投性 = **Go**（赛道先过，再选个股） |
| 技术 | SEPA Stage 2，趋势模板 ≥5/8（同 `/stock-entry`） |
| 顺序 | ETF 打底先建仓 → 再加卫星个股 |
| 账户 | **Roth**（免税，无 LTCG 顾虑，高换手无税务摩擦） |
| 仓位 | 卫星单只 2–3%，1–2 只/赛道（见 `roth-2026.md` 赛道资金比例） |

## 三、出场（区别于蓝筹的三条核心规则）

| 触发 | 动作 |
|------|------|
| 🆓 **免费股**：浮盈 +100% | 卖 50% 收回本金，剩余零成本筹码移动止损骑趋势 |
| 📐 **抛物线顶快出**（任一）：单日 gap +30% / MA50 扩张 >+80% / 量比 >5× | Trim 50% 锁利 |
| 🛑 **论点破坏**（任一）：赛道论文 §11 破坏信号触发 / 个股 changelog 标 weakened·broken / 跌破移动止损 | Exit 全部 |
| ⏱ **无 LTCG 期望** | 不为满 1 年硬持；技术或论点破坏即出 |

**移动止损：** 近 10 日高 − **2×ATR**（比蓝筹论文止损更紧）。

## 四、与现有工具的关系

- `/stock-entry <个股>` — 入场轴心计算（无需改，赛道闸门由本 playbook 前置）
- `/stock-exit --profile hot-sector` — 出场计划用本文出场表（见 stock-exit §3.5）
- `/morning-check ALL` — 持仓矩阵 + 赛道热度修正已覆盖日常监控
