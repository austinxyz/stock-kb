### 营收波动性说明

UUUU 营收由**铀合同交付时序**主导，而非连续生产。铀按长期公用事业合同
批量销售；收入确认因交付时间表不同而在季度间大幅波动，这是合同驱动
业务的正常特性，而非运营失误。

## 估值参考

### EV / 前瞻营收（以 $3.6B EV 为基础）

| 2027 年营收预估 | EV/营收倍数 |
|---------------:|:----------:|
| $1.10 亿（空头）| 32.7× |
| $1.60 亿（基础）| 22.5× |
| $2.50 亿（基础+ SX 投产）| 14.4× |
| $3.20 亿（多头）| 11.3× |

**以 15× EV/营收**（成熟特种材料可比公司）：
- 空头 $1.10 亿 → 约 $7/股
- 基础 $1.60 亿 → 约 $10/股
- 基础+ $2.50 亿 → 约 $14/股
- 多头 $3.20 亿 → 约 $19/股

**以 20× EV/营收**（战略地位 + 成长溢价）：
- 空头 → 约 $9
- 基础 → 约 $14
- 基础+ → 约 $20
- 多头 → 约 $26

分析师中位数目标 $27 意味着在多头情景营收上给予 20×+ 倍数，
或者对 Ra-226 期权价值给予额外价值。
