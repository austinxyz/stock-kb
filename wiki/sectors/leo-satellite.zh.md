## 1. 赛道定义 + 价值链

低轨卫星（LEO）是在约 300–2,000 km 轨道带部署大型星座，提供宽带、手机直连（direct-to-cell）、对地观测、以及国防/ISR 服务，相比传统地球同步轨道（GEO）卫星延迟极低。投资主题骑在"星链经济"上——可复用火箭带来的发射成本下降，叠加商业 + 国防双轮需求。标的从纯叙事型 pre-revenue（ASTS）到发射基础设施（RKLB）再到影像/数据（PL）。

| 层 | 做什么 | 关键玩家 |
|----|--------|---------|
| 发射 / 入轨 | 火箭、拼车、发射频次 | RKLB, SIDU |
| 卫星制造 / 平台 | 制造航天器与星座 | RKLB (Space Systems), ASTS, SIDU |
| 手机直连 / 连接 | 宽带 + 卫星直连手机服务 | ASTS, GSAT, SATS |
| 对地观测 / 数据 | 影像、地理空间分析 | PL, SIDU |
| 零部件 / 利基供应商 | 子系统、推进、光学 | YSS, GCTS |
| 可投 ETF（太空经济）| 全产业链太空敞口 | UFO, ARKX, ROKT |

## 2. 核心赛道问题

> 发射成本下降 + 手机直连浪潮，能否驱动至少一个可投纯标的（ASTS）实现可持续、规模化的运营商经常性收入（年 $300M+），在 SpaceX 星链垂直一体化、资本优势的星座封锁商业跑道之前——并在 pre-revenue 叙事标的均值回归之前？

论点结构上成立（发射成本下降真实且持久）；约束在于最纯的标的是 pre-revenue 且估值偏高，所以这是入场时机和生存问题，而非论点有效性问题。**商业可行时间线已相对原始预期延后；SpaceX 整合加速，进一步压缩了可投纯标的的生存空间。**

## 3. TAM + 增长

- **太空经济（总）**：~$500B（2025）→ ~$1.0–1.8T（2035），CAGR ~9–12%，由宽带、国防、对地观测驱动。*[估算，行业共识区间——多家银行/咨询机构预测聚集于此，无单一硬来源]*
- **卫星宽带 / 手机直连子段**：增速最快的一块；手机直连 TAM 基本为蓝海（每部手机都是潜在可寻址终端）。*[估算]*
- **发射成本下降**：可复用发射推动 $/kg 入轨成本在过去十年下降约 1–2 个数量级——使大型 LEO 星座经济可行的结构性成本曲线。*[估算]*

> 增长杠杆是双重的：发射成本下降（供给侧）× 蓝海手机直连 + 国防需求（需求侧）。

## 4. 生命周期阶段

**成长** — 成长阶段，投机型属性。星座正在部署，但纯连接标的（ASTS）pre-revenue 或 pre-scale；估值由叙事驱动；波动极大（ASTS 2026-07-16 单日成交量比率 154x，-18.34%）。赛道当前处于深度技术性回调，多数标的低于 MA50 幅度达 30–40%。

> 持有纪律：成长阶段 → **hot-sector-playbook（投机）规则**。按投机仓位 sizing，通过回调/筑底管理入场（不追高），使用免费股（涨 100% 卖一半）纪律，并尊重 pre-revenue 标的在资本生存上的二元性。

## 5. 结构性驱动力

1. **发射成本下降** — 可复用火箭（以及含 RKLB Neutron 的竞争性发射市场）持续压低 $/kg 入轨成本，使大型星座经济可行。这是基础性长期驱动。
2. **手机直连** — 未改装智能手机直连卫星（ASTS 3GPP 架构；星链 Direct-to-Cell）打开蓝海 TAM 与运营商批发经济模型。
3. **国防 / 国家安全需求** — 增殖型 LEO（SDA、ISR、韧性通信）是多年期政府采购顺风，为多只标的（RKLB、PL）去除纯商业需求风险。
4. **对地观测 + AI 分析** — 地理空间数据（PL）随 AI 使影像分析更便宜、更可执行而升值。

*主题 vs 周期：* 驱动 1–3 为结构性多年期长牛（发射经济 + 蓝海需求 + 政府预算）；近期价格走势由周期/情绪驱动，当前处于主动回调。

| 对地观测 / 地理空间数据 | ↓↓ | PL |
| 利基零部件 / 微盘（二元）| ↓ | YSS, GCTS |
| 太空经济 ETF（分散载体）| ↓ 逼近路径A | UFO, ARKX |

- **ASTS** — 最纯的手机直连标的；商业服务发布推进中，但现金消耗高；$54.15，-36.8% 低于 MA50，MA200 已破。相对赛道的个股特异性结构性弱点。
- **RKLB** — 发射 + 太空系统；最接近"卖铲子"的收费公路；有营收，含 Neutron 期权价值。
- **PL（Planet Labs）** — 对地观测数据；$21.98，-37.7% 低于 MA50，MA200 已破，深度回调中。
- **YSS / GCTS** — 微盘利基供应商；二元、低流动性，仅作彩票对待。

## 7. 价值链卡位

各层利润池差异极大。**发射（RKLB）** 是持久收费公路——每个星座运营商都必须购买入轨能力——但资本密集，且与 SpaceX 可复用成本优势竞争。**手机直连（ASTS）** TAM 最大、若成功则护城河最强（3GPP 多运营商架构，与 AT&T/Verizon/Rakuten/Vodafone 的 Tier-1 运营商批发协议），但资产负债表持久性最弱（FY2025 FCF −$1.19B），且正面对抗 SpaceX。**对地观测（PL）** 捕获经常性数据收入，但市场更趋商品化。

**竞争格局：** SpaceX/星链是 800 磅大猩猩——垂直一体化（自有发射）、资本优势，现正推自家 Direct-to-Cell。赛道正在围绕星链的主导地位加速整合，可投纯标的生存空间收窄，竞争者商业可行时间线延后。可投纯标的的问题是 ASTS 能否在星链完全转向运营商无关模式之前锁定足够多 Tier-1 运营商。美国标的主导可投宇宙；这不是封装或光互连那样的中美竞争故事。
