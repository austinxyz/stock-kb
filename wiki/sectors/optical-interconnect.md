## 1. 赛道定义 + 价值链

光互连 = 用「光」替代「铜」在 GPU、服务器、交换机、数据中心之间搬运数据的基础设施层。AI 算力从单卡进化到上万卡协作，**GPU 间互连**成为算力能否兑现的关键；铜缆在速度、距离（>几米衰减）、功耗（占数据中心能耗 30%+）触及物理极限——「铜退光进」是结构性趋势。产业链分工极细，存在大量「隐秘赢家」。

| 层 | 做什么 | 关键玩家 |
|----|--------|---------|
| **上游衬底/外延（瓶颈）** | InP/GaAs 衬底（激光器"土壤"）、SOI 光衬底、外延片 | AXTI(InP/GaAs)、Soitec/SOIT(SOI,法股)、IQE(外延,英股) |
| **激光器/光芯片（最稀缺）** | 激光器(发光)、调制器(写信号)、探测器(收信号)、透镜 | SIVE(高功率激光,瑞典)、LITE、COHR(自产 InP) |
| **光模块/收发器** | 可插拔 400G/800G/1.6T 模块 | COHR、AAOI、LITE、Innolight(A股) |
| **硅光代工（瓶颈）** | 硅光芯片代工（"光互连版台积电"）| TSEM(份额最高)、TSM |
| **DSP / 交换芯片** | 信号处理+纠错、CPO 交换 ASIC | AVGO(领先)、MRVL |
| **光纤（路线无关）** | 物理光纤连接（CPO/可插拔都需要）| GLW(Corning 龙头) |
| **代工/测试** | 代工模块、网络验证 | FN(Fabrinet)、VIAV |

## 2. 核心赛道问题

> **CPO（共封装光学）引发的架构重构**——把光电转换从服务器背面搬进芯片封装内贴 GPU（传输距离厘米→毫米，大降功耗延迟）——随 **NVDA 下一代 Rubin 平台正式引入 CPO**（从"可选"变"必选"），能否驱动光互连从"GPU 配角"re-rate 为"AI 主线万亿赛道"，且**上游瓶颈环节**（硅光代工/光衬底/外部激光器/外延/测试封装）因供给刚性而捕获超额价值——还是 2026Q1 blowoff 已充分定价 2027 预期，目前处于均值回归修正中？

赛道论点 = 强（CPO 必选化 + 铜退光进 + 超大厂 capex 锁产）；约束 = **CPO 量产延至 2027H1 + 所有标的 Stage 3/4 技术面破坏**。论点完整，时序错配。

## 3. TAM + 增长

- **光收发器市场**：~$15–20B（2025）→ $30B+（2028），CAGR ~25–30%（800G→1.6T 升级 + coherent 民主化）*[估算]*
- **CPO（共封装光学）市场**：**$1.6亿（当前）→ $910亿（2028）**——NVDA Rubin 必选化驱动的爆发式增长（赛道最大增量）；**量产时间线已右移至 2027H1**
- **ASP 杠杆**：每代速度（400G→800G→1.6T）在相近制造足迹上 ASP 约翻倍
- **Coherent 光**：400G coherent（原电信专用）进入大型 DC 园区 >2km，扩 TAM
- 增长双杠杆：单元量（AI 集群 scale-out）× ASP 阶跃（速度世代）+ **CPO 架构换代**（时序后移）

## 5. 结构性驱动力

1. **超大厂 AI capex 加速** — Meta/MSFT/Google/Amazon 全部上调 2026 全年 capex；GPU 集群需超低延迟高带宽光链路。光模块需求一度超供给 2 倍。
2. **800G → 1.6T 升级周期** — 每代速度 ASP 翻倍，相同制造足迹更高营收。
3. **铜退光进** — 铜缆 >几米衰减、功耗占数据中心 30%+，物理极限被光纤全面替代。
4. **CPO 必选化（核心驱动，时序后移）** — **NVDA 下一代 Rubin 平台正式引入 CPO**，从可选→必选；AVGO 第三代 CPO 交换机已量产（进度领先 NVDA）；MRVL 收购增强封装内光替铜。CPO 市场 2028 $910亿。**量产时间线已右移至 2027H1（延迟 6-12 个月）。**
5. **NVDA 战投锁供应链** — NVDA 向 **Lumentum/Coherent 各投 $20亿**、向 **Corning 投 $5亿**，系统性锁定光器件+光纤产能；TSEM/LITE 产能 2028 前已被预定。
6. **材料墙** — 激光器用 InP/GaAs、DSP 用 Si，两套生产体系互不兼容 → 专业上游公司护城河（见 §7）。

*主题 vs 周期*：1-3+5-6 = 结构性多年；4（CPO）= 既延展又威胁现有格局的结构性换代，当前处于时序修正期。

## 7. 价值链卡位

**材料墙 = 核心护城河来源**：激光器芯片用 InP/GaAs，DSP 用 Si，两套体系不兼容——上游材料公司有几十年纯度/配方积累 + 长客户认证周期 + 高切换成本。

**瓶颈环节（视频认为投资价值所在）**：需求爆发时的关键卡点 =
- **硅光代工**（TSEM "光互连版台积电"，产能 2028 前预定，台积电不熟此工艺）
- **光衬底 SOI**（Soitec 独家 Smartcut 专利垄断）
- **外部激光器**（SIVE/AAOI 给 CPO 供光）
- **外延片**（IQE "千层饼"纳米配方）
- **InP/GaAs 衬底**（AXTI）+ **测试封装**

利润池：上游瓶颈材料/激光 IP（护城河最深但需求传导滞后）> 高毛利 coherent 系统（CIEN/COHR）> DSP/ASIC 硅价值（MRVL/AVGO，CPO 优势）> 商品化可插拔模块（AAOI/Innolight，ASP 承压）> 薄毛利代工（FN）。

**中国格局（保留）：** 中际旭创(Innolight, 300308.SZ) 全球最大光模块产量；新加坡/泰国子公司 TeraHop(铽合科技)服务美国超大厂，ADIA 参与融资（疑 pre-IPO）。

| 维度 | Innolight/TeraHop | 美股(COHR/AAOI/LITE) |
|------|--------------------|----------------------|
| 成本/规模 | ✅ 更低 COGS，#1 量 | ❌ 制造成本更高 |
| 量产速度 | ✅ 最快 | ❌ 较慢 |
| 激光器 IP | ❌ 外购 EML/VCSEL | ✅ COHR 自产 InP |
| CPO 能力 | ❌ 落后 | ✅ AVGO/MRVL 领先 |
| 美股可投 | ❌ 仅 A 股 | ✅ NYSE/NASDAQ |

**底线**：Innolight 赢在可插拔量+成本；美股护城河在器件 IP、CPO 架构、coherent 系统。
